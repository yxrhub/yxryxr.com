# yxryxr.com

《云下人：无限世界》官方落地页（静态站点）。

## 本地预览

在仓库根目录启动任意静态服务器，根目录指向 `dist/`，例如：

```bash
npx --yes serve dist
```

或直接用浏览器打开 `dist/index.html`（部分环境对外链与字体 CDN 无影响）。
